# 更新记录

## v0.3.1 — 2026-10-24

- 接入用户提供的 Musica Logo，主界面左上角常驻显示。
- 原生 .app 使用品牌 ICNS，Finder/Dock 显示同一 Logo。
- 资源内置在应用包中，升级不依赖原图路径，不改动数据与配置。

## v0.3.0 — 2026-10-23

- 新增点击/拖动进度条定位，暂停定位、播放前预选起点。
- 方向键调整 5 秒，Home 回开头，End 到末尾附近；重播/切题重置。
- 保留正式活动计题规则，定位不揭晓答案、不重复记题。
- 提供 Apple Silicon 和 Intel 原生 DMG/ZIP；同名 app 支持新装和替换升级，保留 Application Support 中的数据与配置。
- 原生包写入 0.3.0 版本信息，检查架构、签名、包内播放定位与旧数据保留。

## v0.2.0

独立 Mac 项目，提供曲库、编号、离线答案表、正式活动多轮去重与退出恢复。用户于 2026-10-23 确认可以在 Mac 使用。
